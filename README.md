# TG Supplements

Mini loja de suplementos desenvolvida com React Native + Expo.

## Tecnologias utilizadas

### Frontend

* React Native
* Expo
* Expo Router
* Zustand
* Axios

### Backend

* Flask
* SQLite
* JWT Authentication
* SQLAlchemy

## Funcionalidades

* Login
* Cadastro
* Logout
* CRUD completo de produtos
* Categorias
* Relacionamento produto-categoria
* Navegação entre telas
* Gerenciamento global de estado

## Integrante

* Vinicius Rocha

## Como executar

### Frontend

```bash
cd frontend
npm install
npx expo start
```

### Backend

```bash
cd backend

python -m venv venv

.\venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
